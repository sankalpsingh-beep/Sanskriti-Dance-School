# Sanskriti website — heritage design update

## What changed
- Added a Mysore Palace Darbar Hall architectural reference as a heritage background texture across the home hero, welcome section, learning pathways, and page introductions.
- Updated the visual language to use maroon, antique gold, parchment, and carved-stone framing.
- Redesigned the learning cards as ornate archways with a carved architectural strip at the left and the copy aligned to the right.
- Reduced the hero headline size and increased the readability of the supporting copy.
- Preserved the existing Sanskriti logo, dancer video/poster, Namaskar image, ghungroo ornament, and Aparajithe artwork.
- Added the sixth Natyashastra learning pathway to match the reference layout.
- Added responsive layouts for desktop, tablet, and mobile.

## Run locally
1. Extract the ZIP.
2. Open a terminal in `Sanskriti-Dance-School`.
3. Run `npm install`.
4. Run `npm run dev`.

The architectural reference is loaded from Wikimedia Commons, so it needs an internet connection. Source and attribution are listed in `IMAGE_CREDITS.md`.

## Build note
The build could not be verified in this Linux workspace because the uploaded Windows `node_modules` archive does not contain Rollup's Linux optional binary. Please run `npm install` on your machine before building; this refreshes the platform-specific dependencies.
